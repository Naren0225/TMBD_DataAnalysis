
# Movie Analysis  

## Overview  
This project analyzes movie data to extract insights such as trends in box office collections, genre popularity, and correlations between different features. The analysis is performed using Python and Jupyter Notebook.  

## Features  
- Data Cleaning and Preprocessing  
- Exploratory Data Analysis (EDA)  
- Visualization of Key Trends  
- Statistical Analysis  

## Technologies Used  
- Python  
- Pandas  
- NumPy  
- Matplotlib / Seaborn  
- Jupyter Notebook  

## Installation  
1. Clone the repository:  
   ```bash
   git clone (https://github.com/Naren0225/TMBD_DataAnalysis.git)
   ```
2. Install dependencies:  
   ```bash
   pip install -r requirements.txt
   ```
3. Run the Jupyter Notebook:  
   ```bash
   jupyter notebook MovieAnalysis.ipynb
   ```

## Usage  
Open the Jupyter Notebook and run each cell sequentially to analyze the movie dataset.
